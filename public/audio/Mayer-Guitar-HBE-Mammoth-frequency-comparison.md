# HBE Mammoth 音频频段对比

比较文件：

- `Mayer-Guitar-HBE-Mammoth-FretFlow-reference.wav`：FretFlow 的 NAM2 离线参考
- `Mayer-Guitar-HBE-Mammoth-MCU-mono.wav`：Pico + WM8978 + IXO12 回录

两份文件均按 48 kHz 处理，比较重叠区间为前 24.015 秒，分段长度为 1 秒。

## 全区间频段 RMS（dB）

| 频段 | FretFlow 参考 | MCU 回录 |
|---|---:|---:|
| 20–250 Hz | -46.09 | -67.76 |
| 250 Hz–1 kHz | -56.09 | -81.79 |
| 1–4 kHz | -56.36 | -80.61 |
| 4–8 kHz | -72.42 | -84.89 |
| 8–20 kHz | -48.54 | -46.00 |

## 逐秒波形相关性

前 24 秒每个 1 秒区间的相关系数均接近 0（约 -0.02 到 +0.02），说明 MCU 回录不是参考吉他波形的电平变化或简单延迟，而是另一种噪声信号。

## 结论

参考音频的吉他主体位于约 100 Hz–4 kHz；MCU 回录主要集中在 8 kHz 以上。两者当前频段取向不接近，因此不应通过给参考音频加 EQ 来掩盖问题。必须先让 MCU 回录出现 100 Hz–4 kHz 的有效吉他信号，再进行音色频段匹配。
